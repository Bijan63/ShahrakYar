# 🏡 ShahrakYar

A modern residential community management platform.

## Features

- 🔐 JWT Authentication
- 👥 User & Resident Management
- 🏢 Building & Unit Management
- 🗳️ Election Management
- ✅ Candidate Registration
- 🗳️ Secure Voting
- 📚 Swagger API Documentation
- 🐳 Docker Support
- 🗄️ PostgreSQL + Prisma ORM

---

## Tech Stack

- Node.js 22
- Express.js
- Prisma ORM
- PostgreSQL
- Docker
- JWT
- Swagger
